# 教材导入与章节目录 · 0.13.0

PDF 限制为 200 MB、2000 页和 800 万个可提取字符。其他文件仍为 30 MB。实际可用容量受浏览器存储空间限制，导入前检查剩余配额；大 PDF 默认原版阅读。

导入新 PDF 时明确询问是否生成 AI 目录。选“仅导入”不发起模型请求；PDF 原有书签直接保存为目录。选“生成目录并导入”会在本机保存并打开文件后开始生成，期间可继续阅读。没有模型时提示先连接模型，再手动生成。

AI 使用当前模型连接，每页提取开头的简短文字与页内候选标题，按最多 32000 字、160 页分批，最多两个请求同时进行。只接受有当前物理页面原文标题证据的条目；不将目录页列出的印刷页码当作目标。AI 仍可能漏掉或错误识别章节，可切换原有书签或手动输入物理页码核对。扫描件可以打开原版；没有文字层时，AI 目录需先在其他工具完成 OCR。

左侧目录使用章 → 节 → 小节的三级嵌套结构，大章节支持折叠与展开。搜索小节时保留所属大章节与中间层级；支持当前章节标示和跳页。原版与流式模式均按物理页定位；切换模式保留当前页。窄窗口使用覆盖式目录，点击章节后自动收起。

生成结果存入 IndexedDB `clever-read` 的 `outlines` 对象仓库，并通过文档 ID 关联。已有文档和阅读记录保留，数据库升级至 5。重新打开文件、刷新页面或重启本地服务都不自动调用模型。只有用户选择生成或手动重新生成才发送请求。停止、错误和中断保留上一次完整结果；没有完整结果时保留原有书签。目录保存在当前浏览器的本机文档库；清除站点数据或换浏览器后不会自动迁移。

原版 PDF 保留轻量页面占位，使用真实页面尺寸避免混合纸张跳页漂移；最多两个后台页面渲染任务，回收远处画布，保留约八页渲染缓存。PDF 解析支持取消。

本轮只增加任务 1 所需的导航。任务 2 已确认左侧可收起目录、中央正文、右侧按需 AI；整体视觉改版需要先讨论并确认预案。

整体阅读界面独立预案：`/previews/reader-0130.html`。仅使用自编教材示例，支持浅灰/石墨黑、目录和 AI 栏切换，不调用模型、不改变实际文档库。

## 可选双页阅读 · 0.13.1

PDF 原版阅读中，没有对照翻译时，显示“单页 / 双页”选择。默认单页；双页将 1–2、3–4 等连续页并排，最后一页为奇数时只显示该页。

用户进一步确认允许整页等比例缩放，优先两页完整并排与屏幕利用率。双页统一纸张尺寸，默认“铺满宽度”；“完整双页”同时适配宽与高，一次看全两张纸。PDF 原排版不重排，实际显示字号随整页同比例缩放。混合横竖页面放入相同纸张容器，保留原始长宽比。

左右栏均收起后，去掉外围窗口边框、圆角和大留白，压缩工具栏与页间间距。每份 PDF 的模式和适配方式随阅读位置保存。打开左右任一侧栏时始终保留双页，重新分配剩余宽度。两侧都打开时是“目录｜左页｜右页｜AI”四列，不删除中间任何一页。通过约 220ms 的原位缩放与平移连接前后布局，键盘操作和系统减少动态效果时直接完成布局。
独立预案 `/previews/reader-0130.html` 同步支持两侧收起后的单/双页选择，统一书页大小并等比例缩放。整体视觉改版仍未合入正式界面。

次要功能收进“更多阅读功能”，精简常驻工具；侧栏排版变化复用已打开的 PDF，避免重新读取整本教材。
