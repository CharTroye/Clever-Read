# Clever Read 动画优化计划

日期：2026-10-26。v0.9.0 已完成专注阅读与词旁释义到侧栏的衔接，其余项目继续按下述顺序推进。

## 本轮已完成

- “纸本”作为第四种风格保存，与瑞士排版、编辑档案、经典石墨并列，支持浅色与石墨背景。
- 全部风格共用连续运动机制，覆盖主视图、文档转场、解读栏、设置和导入等弹窗、菜单、术语浮窗、提问反馈。
- 临界阻尼运动接续当前位置与速度；文档过渡等比缩放；弹窗关闭立即释放输入。键盘操作、动效关闭与系统减少动态效果采用即时空间状态。
- 阅读时保持正文稳定，PDF / PPT 原版颜色不随纸本风格染色。

## 实施顺序

### P1：选区、短释义、完整解读保持同一对象

v0.9.0 已完成：文档默认隐藏侧栏，正文适应完整阅读区域；词旁浮窗就地出现，继续解读或追问时先移到右侧，再展开为解读栏。移动与展开均支持中断，沿用短释义的结果或正在进行的请求；键盘操作与减少动态效果采用即时切换。阅读区域加宽，并保留侧栏展开前后的阅读位置。

点击词语后，在词语旁出现短释义；展开时，让这个释义区域延续到解读栏，纸页不跟着漂移。浮窗和完整解读使用同一份结果与请求状态，避免重复请求和两处同时播放相同内容。由选词变为选句时，先更新选区标记，再更新解读标题与正文。

采用约 180–240 ms 的主要空间变化；标题和正文最多错开 30–40 ms，不逐字、不逐行飞入。键盘路径直接切换。验收：展开中反向关闭、快速选择另一个词、模型晚返回时，都只保留正确的当前选区。

### P1：提问与生成状态在原有区域重组

保留上轮可阅读的解读，新问题成为一个稳定的问答条目；等待、回答、失败和停止都在这个条目中变化。当前结果不因新请求被整体清空。发送控件保持位置和尺寸，箭头在 100–140 ms 内收束成停止标记，完成后恢复。输入框保留用户在生成期间新写的草稿。

真实请求多长就显示多久，不添加固定等待或虚假进度。验收：停止、重试、请求失败、切换文档和新草稿输入均保留正确内容，不出现空白跳变。

### P2：文档卡组使用稳定节点

目前卡组切换仍会重建封面节点，限制了快速连点时的连续性。下一步按文档 ID 保留前后卡片，方向键与按钮共用状态；选中卡先进入主位置，再更新标题、阅读位置等信息。打开文档时优先衔接真实页预览，缩短内容就绪与可见之间的空档。

主运动约 220–280 ms，辅助信息最多延后 30–50 ms。普通浏览不复制视频中的大幅旋转、透视翻转和余额滚动。验收：连续前后切换始终落在最后选择的文档，PDF / PPT 不出现变形、旧页残影或选区错位。

### P3：保存与外观切换形成有去向的反馈

新增模型保存后，让实际新增的模型行进入并短暂强调；切换配置时移动选中标记，不重建整张设置表单。设置窗口的出入路径与设置入口保持对应。外观切换让纸面、衬底、边框与文字在同一进度内协调变化，保留文档阅读位置。无需增加常驻提示、彩带或额外导航标签。

保存尾帧约 140–180 ms；主题色阶过渡约 180–220 ms。验收：取消恢复原设置，重复打开不会叠层，焦点回到合理位置，原版文件颜色保持不变。

### P4：在真实负载下调整运动执行方式

以大 PDF 重绘、模型返回与文档切换并发为重点，检查长帧和可点击目标的实际位置。固定路径的转场优先交给合成线程；需要反向接续的运动保留速度状态。减少临时视觉副本与多次布局测量，补充真实页面对象的连续承载。

这一步需要在用户常用设备上确认质感，不能以单元测试通过替代。重点看操作是否立即响应、运动中能否反向、文本是否稳定以及是否出现残留层，而不追求给每一个元素添加动画。

## 保留的边界

不添加页边批注、不劫持滚动、不让正文做视差、不对高频键盘操作增加等待、不照搬展示视频的大幅 3D 与循环装饰。视频给出的是状态关系与编排思路；以上时长是为阅读应用新选的参数。
