# Reading Studio · v0.11.0

## 已实现

采用已确认的 Reading Studio 预案：阅读视图集中在顶栏，普通阅读时隐藏空闲上下文行；引用列表改为原生可折叠摘要；区分问题、回答与原文出处，保留有边界的纸张和辅助面板。沿用四种风格及深浅背景。

释义分成两步：词旁请求约 40–100 字的短释义并实时显示；用户继续解读时再请求完整回答，追问时可以直接携带原文进入问答。

短释义和完整回答按文档、选区位置、上下文、模型、深度和必要历史生成缓存键。缓存保存在 IndexedDB，刷新后可复用。最多约 800 条、有效期 30 天；不保存失败或未完成输出。词旁缓存提供刷新入口。

官方 DeepSeek Flash / V4 Pro 的短释义使用非思考模式；该扩展参数不发送到其他兼容接口。完整解读保留原有模型配置。

## 全文预读的下一步方案

导入文档时由本机分段并建立原文位置；后台按当前页、相邻页、剩余章节的顺序，生成主题梳理、专有名词释义与句段解释。结果按原文位置缓存。用户先开始阅读，预读提供进度、暂停、继续和范围选择。

直接命中的释义从本机展示；未准备的词句、跨段推理与自由追问仍调用模型。长文不应只压成一个摘要供后续全部回答，具体判断继续检索原文并保留可核对出处。预读不等于微调或让无状态接口永久记住文档。

首版复用现有分段、原文检索和 IndexedDB，无需部署额外向量数据库。预读范围可选当前章节或全文，当前页优先；在界面标明预读会调用所选模型并产生服务商费用，后台任务可随时暂停。本版本未启动自动预读或任何批量外部调用。

## 依据

- [DeepSeek 思考模式](https://api-docs.deepseek.com/guides/thinking_mode/)：默认启用思考，默认强度为 high；支持显式关闭。
- [DeepSeek 上下文缓存](https://api-docs.deepseek.com/guides/kv_cache/)：复用输入前缀，输出仍由模型生成，命中率及保存时间没有永久保证。

本轮以模拟模型验证真实流传输、短长回答分离和跨刷新缓存复用，未使用用户的外部 API 进行速度或效果测量。
