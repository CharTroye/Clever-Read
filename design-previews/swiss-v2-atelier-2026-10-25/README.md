# Clever Read — Swiss Atelier v2

Interactive interface proposal saved on 2026-10-25. Open `index.html` in a browser.

- Geometric document covers, layered cover previews, and document thumbnails.
- Continuous transitions between the library and reader.
- Animated appearance selection, question transfer, and reply states.
- Swiss, Editorial Archive, and Classic Graphite styles.

`source.html` contains the editable visualization fragment. `MOTION.md` records the reference analysis and its application. The earlier Swiss v1 snapshot remains separate and unchanged.

This is a local proposal with demonstration content. It does not modify the application, import real documents, or call a model service. Shared preview resources may require an internet connection.
